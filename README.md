# 日麻分析器（Riichi Mahjong Analyzer）

一个功能强大的电脑端日麻（立直麻将）分析助手，支持牌局分析、牌效计算与安装包下载。

## 功能特性

- 牌局分析：快速评估当前牌局形势
- 牌效计算：辅助判断最优切牌与听牌选择
- 支持多版本安装包，持续迭代更新

## 安装

从仓库根目录下载对应版本的安装包（`日麻分析器_vX.X安装包.zip`），解压后运行即可。

当前最新版本：**v3.7.1**（`日麻分析器_v3.7.1安装包_20260816.zip`）
